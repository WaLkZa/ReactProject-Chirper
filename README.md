# Chirper React + Vite

A single-page web application (SPA) built with React + Vite, using JSX, AJAX, REST, and JSON, with a custom [backend](https://github.com/WaLkZa/chirper-fullstack-app).
The app manages users and chirps (tweets). Users can register, log in, log out, view a feed page (showing all chirps from followed users, sorted by time in descending order), create and delete chirps, view their own chirps, discover new people, view all chirps by a specific user (also sorted by time in descending order), and follow or unfollow other users.
